# Privacy Policy — Shorts Auto

_Last updated: 2026-11-12_

Shorts Auto ("the App") is a personal desktop tool that creates short videos and uploads them to YouTube channels owned and operated by its developer. It is not offered to the public. The App uses YouTube API Services.

## 1. YouTube API Services
By using the App you are agreeing to be bound by the YouTube Terms of Service: https://www.youtube.com/t/terms
Google's Privacy Policy applies to data handled through YouTube API Services: https://policies.google.com/privacy

## 2. Data the App accesses
When the channel owner signs in with Google, the App may access:
- **Basic channel information** (channel ID, title) to know which channel to upload to.
- **Upload permission** (`youtube.upload`) to publish videos the App rendered.
- **Video and channel statistics** (views, likes, watch time) through the YouTube Data API and YouTube Analytics API, to show performance on a local dashboard and adjust future content topics.

The App does not access comments, subscribers' personal data, messages, or any other user's data.

## 3. How data is used
Data is used only to:
- upload videos to the signed-in owner's own channels;
- display statistics on a dashboard running on the owner's own computer;
- choose and improve future video topics for those channels.

Data is never sold, shared with third parties, or used for advertising.

## 4. Storage and security
- OAuth tokens and statistics are stored **only on the owner's local computer**. There is no external server or database.
- Tokens are kept in a local file readable only by the owner's Windows account.
- Statistics are kept as long as the owner uses the App and are deleted when the App's data folder is deleted.
- Data obtained from YouTube API Services is refreshed or deleted within 30 days as required by the YouTube API Services Developer Policies.

## 5. Third parties
The App sends **video script text** (not YouTube user data) to Google's Gemini API to generate scripts and metadata, and sends search keywords to Pixabay/Pexels to find licensed stock footage. No YouTube user data is shared with these services.

## 6. Revoking access
You can revoke the App's access at any time at Google's security settings page: https://myaccount.google.com/permissions
After revocation the App deletes stored tokens on next launch.
